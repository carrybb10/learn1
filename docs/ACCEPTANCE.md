# 手动验收清单

> 用途：每发一版（打 tag 前）过一遍。GUI 播放器没有自动化测试，这份清单就是唯一的安全网。
> 记录方式：把结果贴在对应 Release 的说明里，或更新 `PROGRESS.md` 的"当前状态"。
> 编号与 `ROADMAP.md` §2 的 FR/NFR 对应。

## 0. 前置准备

| 素材 | 用途 |
|---|---|
| 1080p H.264 + AAC 的电影（30 分钟以上） | 基本播放、长跑 |
| 4K HEVC 60fps | 硬解与零拷贝 |
| 音频 44.1kHz / 48kHz 立体声各一 | 无损直通 |
| 多音轨视频（可选，M8 前用不到） | 音轨切换 |
| 一个 `.srt` 和一个 `.ass` 字幕 | 字幕 |
| 一个后缀改错/截断的文件 | 异常文件容错 |
| 中文/英语/日语/韩语语音各一段 | AI 字幕 |

启动方式：`build\Debug\MediaPlayer.exe`（调试版）与 `dist\MediaPlayer.exe`（便携版）各跑一遍。

## 1. 功能验收

### 播放与渲染

| # | 场景 | 步骤 | 通过标准 |
|---|---|---|---|
| A1 | 打开并播放 | 拖入 1080p 文件 | 首帧 ≤ 1.5s；画面比例正确；有声音 |
| A2 | 硬解 4K60 | 播 4K HEVC 60fps，任务管理器看 CPU/GPU | 解码线程 CPU < 15%；GPU 有占用；看不出卡顿 |
| A3 | 软解回退 | 关闭"硬件解码"重开 A2 的文件 | 不崩、不花屏；画面正常；CPU 升高但可播 |
| A4 | 暂停/继续 | 播放中暂停 5 秒再继续 | 从原位置继续，音画同步 |
| A5 | 停止 | 点停止后重新打开同一文件 | 能正常重播；无残留声音 |
| A6 | 音量 | 拖到 0 / 50 / 100 | 0 静音；变化平滑；无爆音 |
| A7 | 全屏 | 双击进入，ESC 退出 | 切换后 UI 窗口仍跟随；视频不拉伸变形 |

### seek 与时间

| # | 场景 | 步骤 | 通过标准 |
|---|---|---|---|
| B1 | 单击 seek | 进度条点中间 | 画面响应 ≤ 200ms；**音画对得上** |
| B2 | 连续 seek | 快速点 10 个不同位置 | 界面不冻结；最终位置正确；声音不重影 |
| B3 | 暂停中 seek | 暂停 → 点进度条 → 继续 | 从新位置播放，无旧画面残留 |
| B4 | 末尾 seek | 拖到 95% 处 | 正常播放到结尾；自动连播下一集 |

> B1–B4 是 v0.4.1 修复的四个缺陷的直接验收项，**每次都要过**。

### 字幕与列表

| # | 场景 | 步骤 | 通过标准 |
|---|---|---|---|
| C1 | 加载 SRT | 播放中文对白视频 + `.srt` | 字幕按时出现；误差 ≤ 100ms |
| C2 | 加载 ASS | 同上换 `.ass` | 时间轴正确（不要求渲染样式） |
| C3 | 字幕拖动 | 拖动字幕窗到画面上方 | 位置保持；重启后不要求记忆 |
| C4 | 播放列表 | 添加 3 个文件，双击第 2 个 | 从第 2 个开始播；播完自动下一个 |
| C5 | 列表边界 | 在最后一个文件时播完 | 停在最后，不崩溃、不循环报错 |

### 截图 / 拖拽 / 配置

| # | 场景 | 步骤 | 通过标准 |
|---|---|---|---|

## 2. 非功能验收

| # | 项 | 方法 | 通过标准 |
|---|---|---|---|
| F1 | 翻译正确性 | `build\Debug\translate_cli.exe --model <gguf> --lang 中文 --input tests\translate_samples.txt`（中/英/日/韩各一次） | 28 句全部非空；目标语言正确率 ≥ 90% |
| F2 | 长跑稳定性 | 循环播 1080p 文件 2 小时 | 不崩；`crash_reports/` 无新增；内存不持续增长 |
| F3 | 反复切换 | 连续打开/关闭视频 50 次 | 不崩；任务管理器句柄数不持续上涨 |
| F4 | 空闲占用 | 暂停状态挂 5 分钟 | CPU < 5%；内存稳定 |
| F5 | 崩溃可诊断 | 人为制造一次崩溃（调试版断点 `__debugbreak()` 或触发已知异常） | `crash_reports/*.txt` 里有 `模块!函数+偏移 (file:line)` |
| F6 | 便携版 | 解压 `dist` 到干净目录运行 | 能播放；缺模型时给提示而非崩溃 |
| F7 | 构建可复现 | 干净目录 clone → `scripts\fetch-deps.ps1` → `cmake --build` | 30 分钟内产出可运行的 exe |

## 3. 出问题怎么查

1. 看 `logs\mediaplayer_<时间>.log`（结构化，带模块与行号）
2. 看 `crash_reports\` 最新 `.dmp` + 同名 `.txt`（符号化栈，最多 40 帧）
3. 需要别人复现时：诊断面板一键导出诊断包（系统信息 + 配置 + 最近日志）
4. 崩溃栈里的 `模块!函数+偏移` 可直接对源码定位；若显示 `+0x...` 无函数名，说明 PDB 缺失——确认用的是 Debug/RelWithDebInfo 构建
