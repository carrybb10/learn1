# UI 重构大纲（2026-11-04 定稿）

> 目标：把「能用的播放器」升级成「体验优先的播放器」。
> 本文是逐层推进的大纲，每层开工时对照本节，不要一次改太多。

## 0. 关键架构决策

视频必须和 UI 在同一个合成器里，否则下面三件事做不到：

1. 全窗口毛玻璃拖放悬浮（要模糊视频后面的内容）
2. 视频区平滑放大到全窗口（要对视频做几何动画）
3. 自定义图片背景（视频未播放时露出底图）

实现方式：`VideoSurface` 接口 + 两个实现。
- 先保留 `createWindowContainer`（原生子窗口），跑通现有播放链路。
- 再替换成 `QRhiWidget`（Qt 6.12 自带 D3D11 后端），视频变成普通控件，UI 可叠加。

已确认的硬约束（不要再重复验证）：
- 原生子窗口 `createWindowContainer` 永远盖在普通 QWidget 兄弟之上。
- QWidget 子控件不支持 `windowOpacity`；动效只能动 `pos/opacity`，或用 `QGraphicsOpacityEffect`。

| 层 | 名称 | 覆盖目标 | 依赖 |
|---|---|---|---|

| Layer 1 | 主窗口骨架与空态 | ② 左侧设置栏 + 右侧空态 | 0 |
| Layer 2 | 拖放交互 | ③ 毛玻璃全窗口 + 提示语 | 1 |
| Layer 3 | 视频表面与呈现 | ④ 平滑放大 → 加载 → 无缝播放 | 2 |
| Layer 4 | 播放 Chrome | 控制条/进度/字幕（未显式提但必需） | 3 |
| Layer 5 | 设置与菜单 | ⑤ 预留改动空间 | 1（提前定义接口），实现靠 4 |
| Layer 6 | 插件化接口 | ⑥ 插件预留 | 5 |

## 2. 逐层细则

### Layer 0 — 启动与生命周期
- `SplashWindow`：Logo（美术图先用占位）→ 波浪进度条。
- 波浪特效：自绘 QWidget + 正弦波（进度映射相位），先不做真着色器。
- 状态机：`Splash → Loading → Ready`。
- Splash 只在主窗口 `show()` 后 250ms 仍未就绪才显示，避免闪一下。
- 模型缺失不停 Splash，直接进主界面并提示。
- 必要未提：冷启动 <1.5s（FR-01）。

### Layer 1 — 主窗口骨架
- 左侧固定设置栏（可折叠），右侧内容区。
- 空态：大图标 + 主文案「拖入视频或点击打开」+ 次文案 + 一个主按钮。
- 必要未提：记住窗口几何、恢复上次文件与播放位置、最小窗口尺寸。

### Layer 2 — 拖放
- `dragEnter`：全窗口毛玻璃覆盖 + 居中提示「松开以播放」。
- 毛玻璃：RHI 后对底图高斯模糊；先降级为半透明遮罩。
- `drop`：校验扩展名 → 进入 Layer 3；非法 → Toast 报「不支持的格式」。
- 必要未提：多文件拖入进播放列表、拖入后聚焦窗口。

### Layer 3 — 视频表面（核心，风险最高）
- `VideoSurface` 接口：`resize()/present()/setAspectMode()`。
- 平滑放大：视频区从右半区 `animate` 到全窗口（只动 geometry/opacity）。
- 无缝播放：首帧上屏后才移除遮罩。
- 必要未提：硬解失败回退软解在 RHI 下仍生效；比例/色彩切换；GPU 不可用降级。

### Layer 4 — 播放 Chrome
- 控制条状态机（hidden/shown/timed，暂停常显，拖动锁定），沿用 mpv `osc.lua` 语义。
- 进度条三段（已播/缓冲/悬停预览）、音量、全屏、倍速。
- 字幕：背板 + 安全区（不压控制条）。

### Layer 5 — 设置与菜单
- 左侧栏 = 菜单树，右侧 = 页面；菜单项从注册表生成：`registerMenuItem()`。
- `Ctrl+K` 命令面板（扁平搜索所有命令）。
- 必要未提：设置搜索、二级页面返回保留滚动位置。

### Layer 6 — 插件接口
- `IPlugin` 接口 + `plugin.json` 清单（id/版本/入口/扩展点），动态库加载。
- 三个扩展点起步：菜单项 / 设置页 / 字幕或翻译提供方。
- 必要未提：版本兼容检查、加载失败不拖垮主程序；沙箱后置。

### Layer 7 — 错误与崩溃
- 崩溃弹窗：错误码 + 一键复制 + 打开日志目录（复用已有符号化 crash 报告）。
- 错误码 `E0xx`：解码失败 / 模型缺失 / 显存不足 / 文件损坏，各配一句人话。
- 必要未提：给「下一步做什么」，不只给错误码。

### 主题主线
- `Theme` 抽象：颜色/圆角/间距/字号/动效全部走 token；三套预设 = 换 token 表。
- 自定义图片背景：仅视频未播放时可见。
- 必要未提：跟随系统深/浅色、高对比度、DPI 缩放。

## 3. 推进顺序

```
Layer 0 ─┐
Layer 1 ─┼─→ Layer 2 ─→ Layer 3 (RHI) ─→ Layer 4 ─→ Layer 5 ─→ Layer 6
Layer 7 ─┘                                      ↑
主题主线（横向，贯穿所有层）────────────────────────┘
```

- 0/1/7 先并行（不依赖 RHI），拿到「启动 → 主界面 → 错误弹窗」闭环。
- 2 依赖 1；3 是独立竖切片，先让 `QRhiWidget` 跑通 1080p HEVC 硬解不掉帧再回来。
- 4/5/6 依赖 3，但接口（状态机、菜单注册表、`IPlugin`）可提前定义。

## 5. 验收标准

1. 编译通过，`ctest` 2/2（自动）。
2. `docs/ACCEPTANCE.md` 的 A–E 组行为与重构前一致（手动逐条）。
3. `main.cpp` < 200 行，新增类文件按层划分。
4. 窗口拉伸、全屏进出、播放列表展开无错位（截图 5 张）。
5. 播放/暂停/seek/字幕加载全部正常（冒烟脚本）。
